# Suivre les états et les blocages

## Theory:

Github etat: GitHub has two native states for an Issue: Close or Open.

Dépendance (Dependency): A link between two tasks where one depends on the other.

Bloquée (Blocked): A task that cannot continue temporarily because of a problem or dependency.

Close issue: To close a GitHub Issue when the task is finished and validated.
