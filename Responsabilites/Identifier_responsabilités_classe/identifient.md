# Identifier les responsabilités d’une classe:

## Theory:

**Role:** the main objective or mission of a class.

**Responsabilité:** a specific task that the class performs.

**Cohésion:** is when all the class elements are related to the same goal.

**Couplage(Dépendance):** is when a class need or depends strongly on another class.
